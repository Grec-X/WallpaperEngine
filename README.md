# 手机壁纸引擎

Vibe Coding 项目：全程人机对话完成，无人手写代码。人负责需求、选型、真机验收；AI（ZCode + GLM）负责编码与调试。过程记录在 `docs/日志/`。

把本地视频设为 Android 动态壁纸循环播放，桌面与锁屏独立设置。C# / .NET 9 for Android + Media3 ExoPlayer。

## 功能

- 视频壁纸：循环播放，硬件解码，保持比例裁剪铺满
- 图片壁纸：静态提交给系统
- 桌面 / 锁屏独立设置，可放不同视频或图片
- 播放设置：音量、填充模式、循环区间，两端分别保存
- 壁纸库：历史与收藏各 25 个，显示数量，内容去重，超限淘汰并清理文件
- 收藏豁免淘汰；桌面默认与锁屏默认分开设置
- 熄屏 / 锁屏 / 被遮挡自动暂停，重启自恢复
- 播放出错回退内置素材，状态条标红「播放异常」

## 使用

**首次激活**

1. 启动后授予「照片和视频」权限。用于读取系统当前壁纸，卡片缩略图显示系统真实画面；拒绝仍可用，仅无缩略图。
2. 点顶部橙色状态条，在系统确认页确认绑定。可选桌面、锁屏或两者。

**换壁纸**

- `选择桌面壁纸` / `选择锁屏壁纸`：选视频或图片，选完立即生效。已绑定时不再进系统页。
- ☰ → 点缩略图 → 选「桌面壁纸」「锁屏壁纸」「桌面和锁屏壁纸」，只影响所选位置。

**默认壁纸**

长按缩略图 → 「设为桌面默认」或「设为锁屏默认」。缩略图右下角标注类型。
`恢复桌面默认` / `恢复锁屏默认` 回到对应默认。

**收藏与删除**

长按缩略图 → 收藏（左上角 ★）、从历史中删除（含文件与缩略图）。
使用中与默认壁纸不可删除。

**播放设置**

卡片顶部「编辑对象」切换桌面 / 锁屏，下方音量、画面比例、循环区间载入该端设置并自动保存。

**退回系统壁纸**

未设置默认时，`恢复桌面默认` / `恢复锁屏默认` 将该位置还原为系统壁纸，视频引擎退出。

## 注意事项

- **Debug 版不可直接安装**：FastDev 增量部署，程序集不在 APK 内。卸载重装或系统「清除数据」后启动崩溃。开发用 `deploy.cmd`，日常用 Release 版。
- **锁屏独立播视频需 Android 14+ 且厂商开放**：OriginOS 6 实测可用；Android 13 及更早锁屏跟随桌面，应用会提示。
- **系统确认页仅在需要建立绑定时出现**：桌面或锁屏当前为静态画面、或壁纸未激活过。已绑定时换壁纸即时生效。
- **在确认页改选范围**会造成配置与实际绑定暂时不一致，按正确目标重新设置一次即恢复。
- **设为静态壁纸会退出视频引擎**：桌面变图片后引擎停止，状态条显示静态壁纸。
- **静态画面时播放设置不可用**：对应端的音量与循环区间灰显。
- **仓库不含素材与工具链**：`Assets/default.mp4` 和开发工具链（约 3GB）未入库。放入 MP4 再构建；不放也能运行，首次无默认壁纸。

## 性能

Release 构建（AOT），Reno6 Pro：

| 项目 | 数据 |
|---|---|
| 常驻内存 | 77.7 MB |
| 连续循环 | 30 分钟 357 圈，零崩溃，内存无增长 |
| 切换壁纸 | 1~4 ms |
| 循环接缝 | 四种模式肉眼无差异，采用原生循环 |

Neo 9 屏幕密度与素材分辨率更高，常驻内存约 105 MB。

## 构建

依赖 .NET 9 SDK、Android workload、JDK 17、Android SDK（platform 35、build-tools 35）。

```cmd
build.cmd Debug      构建
build.cmd Release    AOT 构建
deploy.cmd Debug     构建 + 安装 + 启动
```

## 技术记录

- Release 构建下 `WallpaperService.Engine` 子类无法编译（内部类 ACW 生成缺陷），由 `fix-acw.ps1` 构建后改写解决。
- 中文路径导致 aapt2 打包失败，改用 ASCII 联接 `G:\WE` 构建。
- ColorOS 13.1 的 `WallpaperManager.WallpaperInfo` 恒返回 null，激活检测改用引擎实例存活判断。
- 厂商确认页无结果回调与范围查询，壁纸归属由壁纸库三选菜单写入配置决定。

详见 `docs/日志/阶段04_管理应用与体验完善_日志.md`。
