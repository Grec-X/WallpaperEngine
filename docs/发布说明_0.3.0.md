# 0.3.0 发布说明

## 这个版本做了什么

之前桌面和锁屏只能共用同一个壁纸。现在两条通道分开了。

### 分开设置

点「选择桌面壁纸」或「选择锁屏壁纸」，各挑各的。视频会循环播放，图片按静态壁纸提交给系统。两边的壁纸互不影响。

系统确认页还在，但只在需要建立绑定的时候出现。已经绑定好之后换壁纸是直接生效的，不用再走一遍系统页面。

### 主界面

顶部两个状态条，一个桌面一个锁屏，显示当前是动态运行中、静态壁纸还是没设置。下面两张卡片各带缩略图。缩略图是从系统读的实际画面，不是我们自己记的，所以显示的和手机上的始终一致。

### 壁纸库

收藏和历史各能放 25 个，标题上标着当前数量。点缩略图选放到桌面还是锁屏，长按可以设默认、收藏、删除。带星标的是收藏，不会被自动清理。

默认壁纸现在分桌面默认和锁屏默认，各管各的。恢复的时候按各自的默认来，没设过就把那个位置还原成系统壁纸。

### 播放设置

音量、画面比例、循环区间可以分别给桌面和锁屏设置，切换编辑对象就行。某个位置正在显示静态画面时，这几个选项会变灰，因为对静态图没有意义。

### 修复

- 把图片设成默认后再恢复，播放器会去解码图片文件，失败后画面停在上一段视频的最后一帧，看起来像视频暂停了。现在会按媒体类型分开处理，图片走静态提交；播放器那边也加了检查，非视频文件不会硬塞进去
- 桌面明明是一张静态图，「恢复桌面默认」却提示已经是默认了，实际什么都没做。原因是判断用的是配置里的记录而不是系统的真实状态
- 静态壁纸的播放设置之前仍然可以拖动，拖动也不生效

### 其他

- 使用说明重写，六节内容覆盖全部功能
- 适配了 Android 15 以后强制全屏绘制的情况，标题不再被状态栏挡住
- 状态条在播放出错时显示「播放异常」，不再出现「显示运行中但画面不动」的情况

## 已知限制

- 桌面和锁屏分别是动态视频时，两端共用一份播放设置和默认壁纸配置
- 图片只能作为静态壁纸，不能像视频一样循环
