## 本阶段目标
完成项目架构讨论，确定平台、技术栈、核心难点应对策略与阶段划分，产出技术方案文档。本阶段不写任何代码。

## 完成事项
1. 平台可行性分析：确认 Android 是唯一可落地视频动态壁纸的平台方向（iOS 不开放第三方视频壁纸 API，鸿蒙技术栈不兼容 C#）。
2. 技术栈选型讨论：对比 .NET MAUI / 纯 .NET for Android / Unity 三条路径，确定 **.NET MAUI（管理界面）+ Android 平台层 C#（壁纸服务）**。
3. 识别并设计两大核心难点的应对：**壁纸 Engine 生命周期对齐**（4.1 节回调矩阵）与**无缝循环策略**（4.2 节三方案对比，V1 用 ExoPlayer 原生循环，交叉淡化列为 V2 增强与风险预案）。
4. 明确 V1 最小可用范围与四阶段推进计划、每阶段验收标准。
5. 确定功耗暂停策略矩阵与性能设计原则（硬解直通、不用 TextureView、内存 < 100 MB）。

## 关键决策（与需求方确认）
| 决策 | 结论 |
|---|---|
| 目标平台 | 仅 Android；测试真机为 iQOO Neo 9（Android 14 / OriginOS，144Hz 屏） |
| 选型原则 | 性能最优优先：解码渲染全部走硬件直通，C# 仅做编排 |
| 技术栈 | .NET MAUI + Android 平台层 C#；播放内核 Media3 ExoPlayer（NuGet 绑定） |
| V1 范围 | 最小可用：本地视频 → 设为壁纸 → 无缝循环 + 基础省电暂停 |
| 测试条件 | 有安卓真机，阶段二起以真机验证为准（模拟器仅作开发过渡） |

## 遗留问题（带入下一阶段）
1. Media3 ExoPlayer 的 C# 绑定包与 .NET Android 当前版本兼容性未验证 —— 阶段二首要验证项，备选方案已写入技术方案 6 节。
2. 壁纸服务与 MAUI App 是否同进程（内存预算影响）—— 阶段二 PoC 时测量后决定。
3. OriginOS 对壁纸进程的省电管控行为未知 —— 阶段三真机实测时专项记录。

## 下一阶段推进计划（阶段二：核心播放 PoC）
- **目标**：最小验证工程跑通"视频 → Surface 循环播放"链路，真机确认无缝循环效果。
- **步骤**：
  1. 搭建 PoC 工程（放 `poc/` 目录，.NET Android 单页应用）；
  2. 先用系统 MediaPlayer 5 分钟级验证链路可通；
  3. 接入 ExoPlayer 绑定包，配置 REPEAT_MODE_ONE 无缝循环；
  4. iQOO Neo 9 真机测试：接缝观察、内存观察、Surface 销毁重建场景（旋转/切后台）；
  5. PoC 结论（含接缝截图/录屏观察记录）写入阶段二日志。
- **验收标准**：真机连续循环 30 分钟无崩溃、无明显接缝、内存 < 100 MB。
- **环境准备清单（开工前自查）**：.NET SDK（含 android workload）、Android SDK Platform API 34、iQOO Neo 9 开启开发者模式 + USB 调试。

## 补充记录（同日）
需求方补充一台备用测试机 **OPPO Reno6 Pro**，确认作为第二测试设备，并问询在备用机上实验是否有影响。

**结论：无影响，且正是推荐做法。** 调试应用在系统沙箱内运行，卸载即完全清除；设为壁纸后随时可在系统设置换回静态壁纸；全程无需 root、无任何不可逆操作。唯一代价是壁纸运行期间耗电略增，备用机场景下可忽略。用备用机做实验同时保护了主力机 iQOO Neo 9 的日常使用。

由此产生的方案修订（已同步进技术方案 v1.0）：
1. **视频导入方式确定为 SAF（ACTION_OPEN_DOCUMENT）**：Reno6 Pro 出厂 Android 11 / ColorOS 11.3（天玑 1200，2021-05 发布），无 Android 13+ 系统 Photo Picker，且国产 ROM 无 GMS、Google 回迁版 Photo Picker 亦不可用；SAF 免存储权限、全版本可用，为唯一稳妥方案。原文"优先采用 Photo Picker"的说法已修正。
2. **明确 minSdk = 26 / targetSdk = 34**，兼容覆盖向下延伸到备用机。
3. **省电风险条目扩充为 OriginOS / ColorOS 双 ROM**：两台机分属 vivo 与 OPPO 两个激进省电阵营，阶段三"国产 ROM 行为记录"升级为双机对照，验证覆盖面反而更广。

带入阶段二的新增事项：
- 连接 Reno6 Pro 时确认实际 Android / ColorOS 版本（设置 → 关于手机），记入阶段二日志；

- 两台机均需开启开发者模式 + USB 调试。
